Monopolises / Methodology

Evidence discipline

Measure only what the sources can carry.

Gate 0 exists to determine whether strategic replaceability can be evidenced without turning Monopolises into an opaque analyst-opinion product.

Evidence classes

S0 — Source-native. A primary source explicitly states the relevant time, capacity, qualification, commissioning, substitution, or deployment fact.

S1 — Mechanical derivation. A reproducible arithmetic or date transformation from S0 facts. The transformation must be recorded.

S2 — Interpretive synthesis. A domain judgment is required to decide whether an alternative is viable, equivalent, scaled, or qualified. S2 may inform research notes, but it cannot establish a Gate 0 replacement horizon.

Anti-pseudo-precision rule

If evidence supports a range, the output remains a range. If it supports only milestones, the output remains a milestone sequence. If it supports no time statement, the record is not_evidenced.

Falsifier

The current thesis fails if useful replacement horizons consistently require S2 judgment or if primary sources do not expose enough time, capacity, and qualification evidence to build reproducible records.

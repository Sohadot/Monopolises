# Interface Thesis — Monopolises

**Version:** 0.1  
**Status:** Binding for public foundation

## Core rule

> The interface must not decorate the asset. It must embody the asset's thesis.

Monopolises is currently testing time-to-replace as a lens on strategic power. The interface should therefore make **time, alternatives, constraint, and evidence** legible without pretending that an unverified metric is already known.

## Visual grammar

- **Open field:** viable optionality.
- **Bounded interval:** replacement horizon under evidence.
- **Interrupted path:** a constraint or missing evidence.
- **Multiple endpoints:** alternative routes.
- **Source marker:** a claim boundary tied to evidence.

## Prohibited during Gate 0

- monopoly meters;
- entity power scores;
- animated world maps implying measured global coverage;
- decorative 3D chokepoints;
- red danger styling that implies wrongdoing;
- fake live data;
- visual precision exceeding evidentiary precision.

## Performance and access

The foundation must remain static-first, keyboard-readable, screen-reader compatible, responsive, and useful without animation or JavaScript.

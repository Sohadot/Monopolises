# Gate 0 Closeout — Replacement Horizon Evidentiary Test

**Gate ID:** MON-G0-RH
**Closed:** 2026-08-28
**Verdict:** **FAIL**
**Candidate set:** Five cases, fixed before formal evidence extraction
**Rescue cases added:** 0

## Governing question

> Can a replacement horizon be evidenced reproducibly from public primary sources without requiring subjective analyst judgment?

## Binding answer

**Not in the form required to justify Replacement Horizon as the primary scalable measurement thesis for Monopolises.**

Across the five fixed cases, public primary sources were sufficient to reconstruct milestone sequences, open transitions, capability-restoration events, capacity constraints, qualification constraints, and supply-chain boundaries.

They were **not** sufficient to produce a single canonical strategic Replacement Horizon in any of the five cases without an unresolved methodological choice about at least one of:

- when the replacement clock starts;
- what exact event constitutes sufficient replacement;
- what demand/capacity threshold closes the transition;
- whether qualification must be complete;
- whether the relevant technology frontier is fixed or moving;
- where the supply-chain boundary begins and ends.

Those choices cannot be selected retrospectively merely to make a duration calculable.

## Falsifier evaluation

The evidence exposes substantial S0/S1 material. The failure is not simply a lack-of-data failure.

The failure is that converting those records into a **single strategic replacement interval** consistently requires a methodological decision that the source itself does not make.

- C01 requires a rule for which official milestone starts the clock.
- C02 requires a source-native definition of when domestic HALEU supply is commercially sufficient.
- C03 requires a source-native replacement requirement against which qualified magnet output can be tested.
- C04 requires the replacement object to be fixed before measurement: capability, capacity, or moving-frontier parity.
- C05 requires the scope to be fixed before measurement: processing, qualified commercial output, demand sufficiency, or domestic feedstock.

This meets the Gate 0 falsifier.

## Pass-condition evaluation

The individual evidence-bounded records are reconstructable from cited S0/S1 evidence.

However, no case in the fixed set produced the canonical strategic interval required to justify Replacement Horizon as the reproducible core measurement without unresolved methodological choice.

Therefore Gate 0 does not pass.

## Binding consequence

Gate 0 rejects **Strategic Replaceability v0.1 / Replacement Horizon as the primary scalable measurement thesis for Monopolises in its current form**.

The failed Gate does not authorize:

- a global Replacement Horizon graph;
- Replacement Horizon scores;
- entity rankings;
- Replacement Asymmetry scoring;

- a ratified standard based on the failed metric;

Recurring distinctions observed across them — capability, capacity, qualification, sufficiency, frontier, and supply-chain boundary — are retained as findings only. They are **not** automatically promoted into a successor category thesis.

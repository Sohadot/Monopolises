# Gate 0 — Replacement Horizon Evidentiary Test

**Gate ID:** MON-G0-RH  
**Status:** Open  
**Purpose:** Falsify or support the Strategic Replaceability thesis before scale.

## Governing question

> Can a replacement horizon be evidenced reproducibly from public primary sources without requiring subjective analyst judgment?

## Test design

Use a small fixed candidate set selected before evidence extraction. The candidates should span materially different strategic systems so that the test does not succeed only because one data-rich domain happens to fit.

No public scoring, ranking, or entity accusation is part of Gate 0.

## Required case record

Each candidate case must define:

- `critical_function`
- `current_source_or_system`
- `replacement_target` — what counts as functionally sufficient replacement
- `decision_horizon_context`
- `known_alternatives`
- `capacity_constraint_evidence`
- `qualification_constraint_evidence`
- `deployment_or_build_time_evidence`
- `primary_sources`
- `source_locators`
- `uncertainties`
- `result`

## Evidence classes

### S0 — Source-native
The source explicitly states the relevant time, capacity, qualification, commissioning, expansion, substitution, or deployment fact.

### S1 — Mechanical derivation
A reproducible arithmetic or date derivation from S0 facts. The transformation must be recorded.

### S2 — Interpretive synthesis
A domain judgment is required to decide whether the alternative is viable, equivalent, sufficiently scaled, or sufficiently qualified.

S2 may be recorded in research notes, but it cannot establish a Gate 0 replacement horizon.

## Anti-pseudo-precision rule

If the evidence supports only a range, publish a range. If it supports only a milestone sequence, publish the sequence. If it supports no time statement, the result is `not_evidenced`.

## Falsifier

Gate 0 fails if useful replacement horizons consistently require S2 judgment, or if primary sources do not expose enough time/capacity/qualification evidence to construct reproducible records.

## Pass condition

Gate 0 passes only if a reviewer can reconstruct the qualifying case results from the cited S0/S1 evidence and obtain the same bounded result without relying on hidden analyst assumptions.

## Output restriction

Before Gate 0 closes, the public site may explain the hypothesis and methodology only. It must not publish a global replacement graph, scores, rankings, or scaled entity pages.

# Gate 0 — Replacement Horizon Evidentiary Test

**Gate ID:** MON-G0-RH
**Status:** **Closed — FAIL**
**Opened:** 2026-08-27
**Closed:** 2026-08-28
**Purpose:** Falsify or support the Strategic Replaceability thesis before scale.
**Closeout:** `research/GATE_0_CLOSEOUT.md`

## Governing question

> Can a replacement horizon be evidenced reproducibly from public primary sources without requiring subjective analyst judgment?

## Test design

A five-case candidate set was fixed before formal evidence extraction. No sixth case was added.

## Evidence classes

### S0 — Source-native
The source explicitly states the relevant time, capacity, qualification, commissioning, expansion, substitution, or deployment fact.

### S1 — Mechanical derivation
A reproducible arithmetic or date derivation from S0 facts.

### S2 — Interpretive synthesis
A domain judgment is required to decide whether an alternative is viable, equivalent, sufficiently scaled, or sufficiently qualified.

S2 may be recorded, but it cannot establish a Gate 0 replacement horizon.

## Anti-pseudo-precision rule

If the evidence supports only a range, publish a range. If it supports only a milestone sequence, publish the sequence. If it supports no defensible interval, the result is `not_evidenced`.

## Falsifier

Gate 0 fails if useful replacement horizons consistently require S2 judgment, or if primary sources do not expose enough time/capacity/qualification evidence to construct reproducible records.

## Pass condition

Gate 0 passes only if a reviewer can reconstruct the qualifying case results from cited S0/S1 evidence and obtain the same bounded result without hidden analyst assumptions.

## Verdict

**FAIL.**

All five cases produced useful evidence-bounded records, but **zero of five** produced a single canonical strategic Replacement Horizon without an unresolved choice about start, endpoint, sufficiency, qualification, moving frontier, or supply-chain boundary.

See `research/GATE_0_CLOSEOUT.md`.

## Output restriction after closure

The failed Gate does not authorize a global replacement graph, scores, rankings, scaled entity pages, a ratified standard, or monetization based on Replacement Horizon.

Any successor thesis requires a new decision and a new gate. This Gate is not reopened or retroactively redefined.

Monopolises / Sources

Source register

Authority is not enough. Claim fit matters.

Sources are admitted when they support an actual research case. The register does not grow merely by collecting prestigious publishers.

Admission priority

  1. Primary government, regulator, or public-authority records
  2. Statutory filings and official company disclosures
  3. Official project, capacity, commissioning, licensing, or procurement records
  4. Primary technical documentation
  5. Secondary research only as context or locator assistance

Current status

The Gate 0 public source register is intentionally not populated until candidate cases are fixed. This prevents source collection from becoming a substitute for a falsifiable test.
